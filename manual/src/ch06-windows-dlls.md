# Chapter 6 - Windows DLLs

*Announced as "to be released" in version 1.01 - no content was included.*

---

Version 1.01 of the Ad Lib Gold Developer Toolkit reserved Chapter 6 for the
**Windows DLLs**, but they were not part of this release. The original table of
contents and the release notes both list this chapter as **"To be released,"**
and the [introduction](introduction.md) states that *"the MIDI driver, SCSI
driver and Windows DLLs will be included with the next version."*

Because this edition faithfully reproduces version 1.01, the chapter has no
content. Navigation continues at
[Chapter 7 - Low-Level Programming](ch07-low-level.md). The original chapter
number is preserved so that references to "Chapter 7" and the appendices still
match the source document.
